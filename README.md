## الأقسام
- **الحسابات:** كشف حساب، سند قبض، سند صرف، العملاء، الموردين، أرصدة العملاء والموردين
- **المخزون:** قائمة الأصناف (كود 12 رقماً، وحدات متعددة، ضريبة لكل صنف)، إضافة صنف، جرد المخزون
- **المبيعات:** فاتورة مبيعات (نقداً / بنفت / آجل)، فاتورة تسليم، إيصال حراري 80mm، صرف بضاعة، مرتجع مبيعات من الفاتورة الأصلية، تقارير PDF و Excel ومشاركة عبر واتساب
- **المشتريات:** فاتورة مشتريات، مرتجع مشتريات
- **التقارير:** إقفال اليوم، الأرباح بمتوسط التكلفة، المصروفات بالتصنيفات، سجل التعديلات مع الاستعادة
- **الصلاحيات:** مدير أساسي مخفي، مدير، كاشير

## التشغيل
- **الاستخدام اليومي:** من الرابط أعلاه.
- **تشغيل `index.html` مباشرة** (من جهازك أو أي استضافة) يعمل، لكن البيانات تُحفظ في متصفح ذلك الجهاز فقط (localStorage).

> لا يحتوي المستودع على أي بيانات مالية.
