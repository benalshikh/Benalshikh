# ابن الشيخ — النظام المحاسبي | Ibn Al-Sheikh Accounting

تطبيق محاسبي ثنائي اللغة (عربي / English) في صفحة HTML واحدة.

## الأقسام
- **الحسابات:** كشف حساب، سند قبض، سند صرف، العملاء، الموردين، أرصدة العملاء والموردين
- **المخزون:** قائمة الأصناف (كود 12 رقماً، وحدات متعددة، ضريبة لكل صنف)، إضافة صنف، جرد المخزون
- **المبيعات:** فاتورة مبيعات (نقداً / بنفت / آجل)، فاتورة تسليم، صرف بضاعة، مرتجع مبيعات، تقارير PDF ومشاركة عبر واتساب
- **المشتريات:** فاتورة مشتريات، مرتجع مشتريات

## التشغيل
افتح `index.html` في المتصفح. البيانات تُحفظ في متصفح الجهاز (localStorage) عند التشغيل خارج Claude.
الدخول الأول: `admin` / `admin` — غيّرها من الإعدادات.

> لا يحتوي المستودع على أي بيانات مالية؛ البيانات تبقى على الجهاز.
